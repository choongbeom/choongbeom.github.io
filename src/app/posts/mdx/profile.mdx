## 김충범 | Senior Software Engineer

**C++, C# 기반 장비 연동과 SDK 개발을 장기 실무 기반으로 보유하고, 최근에는 기업용 플랫폼과 AI 문서처리 제품 개발까지 영역을 확장해 온 소프트웨어 엔지니어입니다.**

2009년부터 약 **17년간** 신분증·문서 스캐너, 본인확인기, 키오스크, ATM 등 다양한 장비와 업무시스템을 연결하는 소프트웨어를 개발해 왔습니다.

C++, C#, MFC, WinForms 기반 Windows 응용프로그램과 장비 SDK 개발을 중심으로 인터페이스 설계, 설치·배포, 고객 환경 적용, 장애 분석과 유지보수까지 제품 생명주기 전반을 경험했습니다.

이후 브라우저와 Windows 장비를 연결하는 Local Server, REST API, Windows Agent 구조를 거쳐 Web·API 기반 시스템으로 개발 범위를 확장했습니다.

현재는 개발팀장으로 기술 의사결정과 실무 개발을 병행하며, 제품 요구사항 정의부터 아키텍처, 핵심 구현, 기술 검증과 운영 기준 수립까지 제품 개발의 여러 단계를 연결하고 있습니다.

2026년부터는 기존 장비 소프트웨어 경험을 기반으로 상용 Document AI를 기업 업무에 적용하는 문서처리 제품을 설계하고 구현하고 있습니다.

특정 기술 하나보다는 **장비, 소프트웨어, 고객 업무와 운영 환경을 함께 이해하고 실제 사용 가능한 제품 구조로 연결하는 것**을 강점으로 생각합니다.
